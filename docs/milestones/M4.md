# M4: Gate and validate

**Goal:** block any change that weakens CI, and prove generated pipelines run.

## Scope

- OPA policies in `policy/` evaluated on plan diffs (old plan, new plan):
  stage removed, failure ignored, tests skipped, permissions widened, Action unpinned,
  unsafe trigger, threshold lowered, secret exposure.
- Rego unit tests with fixtures for every rule, both the blocked and the allowed case.
- Gate result stored with the rule names that fired; exceptions require a maintainer
  approval that is written to `audit_events`.
- Sandbox validator: runs the compiled workflow's jobs in a container with no secrets and a
  network allowlist. Jobs needing credentials are marked `not_validated`.

## Exit test

Every "bad" fixture in `policy/testdata/` is blocked with the correct rule name and every
"good" fixture passes. The sandbox validates the M2 fixtures' test jobs end to end.
