# M2: Analyzer

**Goal:** produce a repository profile with evidence for Python, JS/TS, Go and Java repos.

## Scope

- Analyzer job: shallow-clone the default branch into a disposable worker container.
  No execution of repo code.
- Detectors (parsers first): `package.json`/lockfiles, `pyproject.toml`/`requirements*.txt`,
  `go.mod`, `pom.xml`/`build.gradle`, Dockerfiles, Terraform, Kubernetes manifests, existing
  `.github/workflows`.
- Monorepo awareness: one profile entry per app directory.
- Every fact carries an `evidence` list of file paths.
- `uncertainties` list for what parsers could not decide. LLM fallback is optional and off
  by default.
- Profile stored in `repository_snapshots`, shown in the dashboard.

## Exit test

8 fixture repos (2 per language, including one monorepo and one with existing CI) produce
profiles that match hand-written expected JSON exactly.
