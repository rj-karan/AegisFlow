# M3: Recommend and plan

**Goal:** from a profile, pick tools with reasons, build a pipeline plan, compile it to
GitHub Actions YAML.

## Scope

- Tool catalog (`catalog/*.yaml`): license, supported stacks, runtime cost, credentials,
  last-verified date, mandatory flag.
- Rule-based ranker: maximise coverage and reliability, penalise runtime, cost and noise.
  Mandatory controls cannot be ranked away.
- Explanation text per recommendation; LLM-written when a key is configured, template
  otherwise.
- Plan IR: stages, dependencies, working directory, permissions, secrets, severity
  thresholds.
- Deterministic GitHub Actions compiler: read-only permissions, SHA-pinned `uses:`,
  `timeout-minutes`, `working-directory` per app, concurrency groups.
- SHA resolver with a cached pin table.

## Exit test

For every M2 fixture profile the compiled workflow passes `actionlint` and `zizmor` with
zero findings, and compiling the same plan twice yields byte-identical YAML.
