# M1: Foundation

**Goal:** a running monorepo where a user signs in, has a workspace, installs the GitHub
App, and sees the repositories it can access.

## Scope

- Go module with `cmd/api` and `cmd/worker`, `internal/` packages, Makefile, golangci-lint.
- Next.js dashboard in `web/` with a repositories page.
- PostgreSQL schema v1: `workspaces`, `users`, `github_installations`, `repositories`,
  `audit_events`. Migrations with goose, queries with sqlc.
- Redis + asynq wired with one no-op job to prove the queue round-trips.
- GitHub App: installation webhook (HMAC-verified, delivery-ID dedup), installation token
  minting, "list repositories for installation".
- Workspace scoping middleware: every handler resolves a workspace from the session and
  every query takes `workspace_id`.
- Docker Compose for api, worker, web, postgres, redis.
- CI for this repo: go test, go vet, golangci-lint, eslint, actionlint, zizmor. Pinned SHAs,
  read-only permissions.

## Out of scope

Analysis, recommendations, YAML generation. Nothing touches repo contents yet.

## Exit test

Install the App on a test organisation with at least three repos. The dashboard lists
exactly those repos, with `not_configured` status, within one webhook delivery. A second
workspace cannot see them.
