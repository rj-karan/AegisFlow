# M7: Operate

**Goal:** run AegisFlow itself the way a production service is run, so the repository proves
the full DevOps path: code, container, cluster, GitOps, observability, release. This
milestone runs alongside M1 to M6 rather than after them. Everything in it is free for a
student; see [operations/free-tier-plan.md](../operations/free-tier-plan.md).

## Scope

- Terraform creates the cluster: `kind` on the laptop first, then `k3s` on an Oracle Cloud
  Always Free arm64 VM. Same modules, two environments.
- Multi-arch container images for `api` and `worker` published to GHCR on every merge.
- One Helm chart for the whole system with probes, resource limits and a hardened
  `securityContext`.
- Argo CD app-of-apps. Merge to `main` is the only way anything reaches a cluster.
- Prometheus, Loki and Grafana with dashboards and alert rules stored in git.
- Signed releases: GoReleaser, cosign keyless signatures, SBOM, SLSA build provenance.
- Secrets encrypted in git with SOPS and age.
- SLOs, runbooks and recorded failure drills.

## Out of scope

Multi-cluster, service mesh, autoscaling beyond a single node. They are later milestones if
the project outgrows the free tier.

## Exit test

Change one line of Go, open a PR, merge it. Without running `kubectl` by hand, the new
version is live on the cluster, the Grafana dashboard shows its traffic, and
`gh attestation verify` proves the running image was built by this repository's CI.
